Local AI without API keys, plus an offline fallback

Local AI setup (no API key)

Install Ollama on the same computer that runs this Python backend, then run ollama pull qwen2.5:3b. Set optional server variables OLLAMA_BASE_URL and OLLAMA_MODEL. Local models need RAM/disk and can be slow on CPU.

Important: on shared hosting, localhost is the hosting server, not your phone or PC. For local Ollama, run the app backend on your own computer. Offline Template works without a model but is template-based, not a real LLM.

Optional cloud AI setup

Set AI_BASE_URL, AI_API_KEY, and AI_MODEL in the server environment. Never place secret keys in browser JavaScript.
