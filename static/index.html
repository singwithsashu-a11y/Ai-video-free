Browser AI: no API key

Loads a small Qwen 0.5B model into this browser from Hugging Face on first use. Model files can be hundreds of MB and use your phone's RAM/storage. Requires internet for the first download; browser/WebGPU support and performance vary by device. Prompt inference runs on your device after model download. This browser mode does not load your separately trained LoRA adapter.

Use the trained MJ AI adapter

Extract the GitHub Actions adapter into models/mj-ai-lora/ on the backend host, install training/requirements-inference.txt, and set MJ_AI_ADAPTER_PATH=models/mj-ai-lora and MJ_AI_BASE_MODEL=Qwen/Qwen2.5-0.5B-Instruct in the server environment. The base model downloads separately. Adapter inference may be too heavy for shared hosting.

Local Ollama / cloud setup

Ollama runs on the machine hosting the backend, not automatically on your phone. Set OLLAMA_BASE_URL and OLLAMA_MODEL server-side. For cloud AI, set AI_BASE_URL, AI_API_KEY and AI_MODEL on the backend. Never put secret API keys in frontend code.
