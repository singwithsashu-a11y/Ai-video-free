How to make it genuinely local

Important for Android + shared hosting: a website cannot magically bundle every AI model.

📱

Your current setup: Android + hosting

Use this temporary dashboardThe interface and offline template helper run in the browser.
Use the hosting backend for supported tasksFFmpeg and Python depend on your host's installed packages, permissions and time limits.
Large AI models may not run on shared hostingMost shared cPanel plans lack the RAM/GPU and process access for image/video models.
💻

For real local AI without API keys

Install a local runtimeFor example, install Ollama on a PC or server you control.
Download model weights onceExample command: ollama pull qwen2.5:3b. Downloads require internet and disk space.
Connect the backend securelyKeep local model ports private; do not expose an unauthenticated model endpoint to the public web.
No API key does not mean no compute. A true offline model needs downloaded weights and compatible device resources. This demo does not claim that all listed models are installed.
Honest capability note: this is a temporary static preview with a working browser-side template helper and workflow planner. It is not a bundle of every AI model and does not perform real text-to-video, image generation or speech transcription by itself. Connect supported runtimes/backends for those capabilities.
